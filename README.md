# Large Scale Computing

**Carnegie Mellon University (CMU) | Pittsburgh Supercomputing Center (PSC)**

Coursework and projects from CMU's Large Scale Computing class, where I gained hands-on experience with high-performance computing on the Bridges-2 supercomputer.

## Tech Stack
- **Core:** Python, SQL, Apache Spark
- **ML/DL Frameworks:** PyTorch, TensorFlow, scikit-learn
- **Data Processing:** pandas, numpy, PySpark
- **Development:** VSCode, HPC environments

## Key Learning Areas
- Distributed computing with MPI in Python
- Database querying and optimization (SQL)
- Scalable machine learning pipelines with Spark
- Building and evaluating recommender systems
- Processing and analyzing large-scale datasets
- Neural network training and optimization

## Course Information
**Institution:** Carnegie Mellon University  
**Semester:** Fall 2024  
**Platform:** Bridges-2 Supercomputer at Pittsburgh Supercomputing Center
